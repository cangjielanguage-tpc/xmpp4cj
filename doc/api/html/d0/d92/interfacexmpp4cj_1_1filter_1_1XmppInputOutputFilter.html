详细描述

XMPP（可扩展消息和存在协议）中的输入输出过滤接口。 此接口提供了处理输出数据和输入数据的方法，同时允许对过滤器行为进行额外控制。

处理和过滤输出数据。

参数
outputData要作为ByteBuffer过滤的数据。
isFinalDataOfElement指示这是否是正在处理的元素的最终数据。
destinationAddressChanged指示目标地址是否已更改。
moreDataAvailable表示是否有更多数据可供处理。
返回
一个OutputResult，指示过滤后的输出和任何待处理的数据。
异常
IOException如果在输出处理过程中发生错误。
