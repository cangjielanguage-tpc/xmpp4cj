详细描述

用于过滤有效的 IQ 请求回复的数据包。

这样的数据包必须具有相同的 stanza id，并且必须是类型为 RESULT 或 ERROR 的 IQ stanza。此外，还需检查 from 地址，以忽略伪造的回复。

我们接受的 from 地址如果满足以下条件之一：

  • 与请求的 to 地址匹配。
  • 请求的 to 地址为空，并且 from 地址与 服务器的 bare jid 或客户端的 (bare 或 full jid) 匹配。
  • 请求的 to 是我们的 bare 地址，并且 from 为空。

有关问题的讨论，请参阅 2014-01 在 jdev@.nosp@m.jabb.nosp@m.er.or.nosp@m.g 邮件列表中 讨论的“IQ id 的欺骗和表现不当的服务器”主题，以及 2 月和 3 月的后续讨论。
