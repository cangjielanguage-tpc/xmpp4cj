详细描述

接口，允许实现类监听连接关闭和重新连接事件。监听器与 XMPPConnection 对象注册。

参见
XMPPConnection::addConnectionListener
XMPPConnection::removeConnectionListener

◆ connected()

func connected ( ) : Unit

通知连接已成功连接到远程端点（例如 XMPP 服务器）。

注意，连接可能尚未经过身份验证，因此可能仅能进行有限的操作，例如注册账户。

参数
_成功连接到其端点的 XMPPConnection 对象
