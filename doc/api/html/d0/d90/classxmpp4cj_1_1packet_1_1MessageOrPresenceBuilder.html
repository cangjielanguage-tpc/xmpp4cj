public abstract class MessageOrPresenceBuilder <: StanzaBuilder

MessageOrPresenceBuilder 是一个抽象类，用于构建 MessageOrPresence 实例的构建器。

此类扩展自 StanzaBuilder，提供用于特定类型的 XMPP 消息或存在状态的创建方法。
