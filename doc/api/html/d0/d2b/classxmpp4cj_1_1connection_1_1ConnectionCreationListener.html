详细描述

实现此接口的类将在新的 XMPPConnection 被创建时收到通知。 新创建的连接尚未实际连接到服务器。使用 XMPPConnectionRegistry#addConnectionCreationListener(ConnectionCreationListener) 来添加新的监听器。
