初始化与给定主机和端口的连接。请注意，调用者需要负责在此方法抛出异常的情况下关闭 socket。

参数
socket用于与代理建立连接的 socket。
host要连接的主机。
port要连接的端口。
timeout超时时间（以毫秒为单位）。
异常
IOException如果发生 I/O 错误。

在 Socks4ProxySocketConnection , 以及 Socks5ProxySocketConnection 内被实现.
