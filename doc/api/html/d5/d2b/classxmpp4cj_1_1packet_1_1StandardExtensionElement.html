详细描述

一个 ExtensionElement，对使用 XMPP 时经常需要和使用的 XML 特性进行建模。 因此，它适用于大多数用例。 使用 StandardExtensionElement#builder(String, String) 来构建这些元素。

请注意，这仅在没有注册特定的扩展元素提供程序时作为万能方案。 协议实现应该更倾向于为其用例定制自己的扩展元素模型。
