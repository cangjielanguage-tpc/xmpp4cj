详细描述

public abstract class ConnectionConfiguration

用于XMPP客户端到服务器连接的连接配置。 配置良好的XMPP服务通常只需要您提供两个参数：用户的XMPP地址（也称为JID）和密码。理想情况下，所有其他配置参数都可以由Xmpp自动确定。 因此，调用Builder#setXmppAddressAndPassword（CharSequence，String）就足够了。

从技术上讲，通常至少需要两个参数：用于身份验证的某种凭据。 以及XMPP服务域。凭证通常由用于SASL身份验证的用户名和密码组成。 但也有其他身份验证机制，如客户端证书，不需要特定的用户名和密码。

关于XMPP客户端到服务器的参数存在一些误解：首先，用于身份验证的用户名在身份验证后将等于绑定XMPP地址的本地部分。 虽然这通常是正确的，但不是必需的。 从技术上讲，用于身份验证的用户名和由此产生的XMPP地址完全相互独立。 第二个常见的误解来自“XMPP主机”和“XMPP服务域”这两个术语：XMPP服务主机是托管一个或多个XMPP域的系统。 “XMPP服务域”通常是绑定JID的域部分。此域用于验证远程端点，通常使用TLS。 第三个误解是，XMPP服务域需要成为绑定JID的域部分。 同样，虽然这很常见，但并不是严格要求的。

◆ isCompressionEnabled()

public func isCompressionEnabled ( ) : Bool

如果连接将使用流压缩，则返回 true。流压缩将在TLS建立之后（如果启用了TLS）且仅当服务器提供流压缩时才会被请求。通过流压缩，网络流量最多可减少90。默认情况下，压缩是禁用的。

返回
如果连接将使用流压缩，则返回 true。
