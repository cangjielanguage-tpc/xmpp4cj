详细描述

public abstract class XMPPInputOutputStream

抽象类，表示 XMPP 输入输出流。 此类提供了压缩数据时所用的刷新方法，并定义了一些抽象方法，以便子类实现具体的输入输出流逻辑。

public static func setFlushMethod ( flushMethod:  XMPPInputOutputStreamFlushMethod) : Unit

设置压缩数据时使用的刷新方法。默认使用完全刷新，这可能无法达到最佳压缩比， 但能提供更好的安全性以防御某些攻击。仅在完全理解其影响时使用同步刷新。
