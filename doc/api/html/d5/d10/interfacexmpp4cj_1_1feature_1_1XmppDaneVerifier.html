详细描述

该接口的实现定义了一个能够在连接上启用 DANE 的类。

DANE（DNS-based Authentication of Named Entities）是一种可以使用 DNSSEC（DNS Security Extensions）来验证证书的机制。 实现此接口的类需要提供初始化和结束 DANE 验证的功能。
