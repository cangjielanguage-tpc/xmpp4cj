◆ setAuthzid()

public open func setAuthzid ( authzid:  EntityBareJid) : This

设置用作授权标识的XMPP地址。

在XMPP中，授权身份是赤裸裸的。 一般来说，调用者应该允许服务器自动选择授权标识符，而不是调用它。 请注意，设置authzid不会设置XMPP服务域，通常应该匹配。 调用此命令也将是SASL CRAM，因为此机制不支持authzid。

参数
authzid请求BareJid作为授权标识符。
返回
ConnectionConfigurationBuilder
参见
RFC 6120 § 6.3.8. Authorization Identity

设置我们从服务器请求的资源。

如果资源为空-默认值，则服务器将自动为客户端创建资源。 请注意，XMPP客户端仅向服务器建议此资源。 XMPP服务器可以忽略客户端建议的资源，而是分配一个完全不同的资源（见RFC 6120§7.7.1）。

配置用户名、密码和XMPP服务域的便捷方法。提供的JID的localpart用作用户名，domanipart用作XMPP服务域。

请注意，这可以配置也不能配置客户端XMPP地址。XMPP服务不需要分配绑定的JID，其中localpart与用户名匹配，domainpart与验证的domainpart匹配。尽管大多数服务将遵循这种模式。
