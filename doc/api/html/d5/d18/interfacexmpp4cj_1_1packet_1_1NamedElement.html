详细描述

表示 XML 元素的接口。这与 ExtensionElement 类似，但不携带单个命名空间，而是与多个命名空间一起使用。这种情况的例子包括 MUC 的 &ltdestroy/&gt 元素。

请注意，不鼓励使用此接口。原因是每个 XML 元素都是完全限定的，即由命名空间限定。命名空间可能不会明确给出，而是从外部元素继承。在可能的情况下，请使用 FullyQualifiedElement 代替。
