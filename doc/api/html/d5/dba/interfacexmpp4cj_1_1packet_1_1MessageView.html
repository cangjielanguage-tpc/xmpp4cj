func getBody ( ) : ?String

返回消息的默认正文，如果正文未设置则返回 None。正文是消息的主要内容。

消息的默认正文是与消息的语言相对应的正文（见 getLanguage()），或者如果没有设置语言，则为应用程序的默认语言（见 Stanza#getDefaultLanguage()）。

返回
消息的正文。
