详细描述

public abstract class Provider<E> <: AbstractProvider<E> where E <: Element

XMPP 提供者是用于将原始 XMPP 反序列化为相应的 Element 的解析器。

在任何时候调用 parse(XmlPullParser, int, XmlEnvironment) 时都可能抛出任何类型的异常。 如果解析的元素不符合规范，例如在只允许整数的地方放入一个字符串， 那么应该抛出一个 Xmpp4cjException。

参数
<E>结果元素的类型。
