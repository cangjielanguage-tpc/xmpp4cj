详细描述

表示操作的类型，可以是非阻塞或阻塞。此枚举用于区分不同的操作模式。

类成员变量说明

◆ Blocking

Blocking

阻塞操作。

在此模式下，操作会阻塞调用线程，直到操作完成。

◆ NonBlocking

NonBlocking

非阻塞操作。

在此模式下，操作不会阻塞调用线程，调用者可以继续执行其他任务。
