详细描述

public abstract class StanzaFilter <: Predicate<Stanza> & ToString

定义了一种根据特定属性过滤 Stanza 的方法。Stanza 过滤器用于构建 Stanza 监听器或收集器， 过滤器定义哪些 Stanza 匹配收集器或监听器的标准，以便进行进一步的 Stanza 处理。

预定义了几个简单的过滤器。可以使用 AndFilter 和 OrFilter 过滤器逻辑组合这些过滤器，以实现更复杂的 Stanza 过滤。也可以通过实现该接口来定义自己的过滤器。下面的代码示例创建了一个用于特定 ID 的 Stanza 的简单过滤器（真实代码应使用 StanzaIdFilter 替代）。

 // 使用匿名内部类定义一个返回所有具有 Stanza ID 为 "RS145" 的 Stanza 的过滤器。
 let myFilter:StanzaFilter = StanzaFilter() {
     public func accept(stanza: Stanza):boolean {
         return "RS145".equals(stanza.getStanzaId())
     }
 };
 // 使用我们创建的过滤器创建一个新的 Stanza 收集器。
 let myCollector: StanzaCollector = connection.createStanzaCollector(myFilter)

作为经验法则：如果您有一个谓词方法，即一个以单个 Stanza 作为参数、无副作用（纯粹）并且仅返回布尔值 的方法，那么这通常是一个很好的指示，表明该逻辑应该放入 StanzaFilter 中（并在 StanzaListener 中引用）。
