详细描述

可以使用任意K的HashMap

  • K.hashCode()优先级:
    1. K.hashCode()
    2. K.toString().hashCode()
    3. -1
  • K的比较使用EqualsUtil.equals(K, K), 优先级:
    1. K==K
    2. refEq(K, K)
  • 由于不限定K, 所以无法继承Map
