详细描述

XMPP 地址（JID）的“资源部分”。

你可以使用 from(String) 从字符串创建这个类的实例。

参见
RFC 6122 § 2.4. 资源部分

◆ fromOrNull()

public static func fromOrNull ( cs:  String) : ?Resourcepart

从给定的字符序列获取一个资源部分（Resourcepart），如果输入不是有效的资源部分，则返回 None。

参数
cs输入的字符序列。
返回
一个资源部分或 None。

◆ fromOrThrowUnchecked()

public static func fromOrThrowUnchecked ( cs:  String) : Resourcepart

类似于 from(String)，但如果输入不是有效的资源部分，会抛出未检查的 IllegalArgumentException 而不是 XmppStringprepException。

参数

返回
如果没有异常发生，则返回资源部分。
异常

◆ static let EMPTY

let EMPTY : Resourcepart = Resourcepart("")

空资源部分。

这个空资源部分是由空字符串表示的部分。在你有一个不允许为 None 值的资源部分集合，但又要处理“没有资源”的情况时，这很有用。
