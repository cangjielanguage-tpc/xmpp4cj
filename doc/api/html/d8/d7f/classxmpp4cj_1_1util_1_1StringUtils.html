◆ insecureRandomString()

public static func insecureRandomString ( length:  Int64) : String

返回指定长度的由数字和字母（大小写）组成的随机字符串。 该方法使用 Cangjie 内置的 Random 类。 这意味着输出只是伪随机的，即每个数字都是数学生成的，因此不是真正的随机。

指定的长度必须至少为一。如果不是，该方法将返回 None。

参数
length要返回的随机字符串的所需长度。
返回
指定长度的数字和字母组成的随机字符串。

◆ secureOfflineAttackSafeRandomString()

public static func secureOfflineAttackSafeRandomString ( ) : String

生成一个人类可读的安全随机字符串。结果字符串由 24 个拉丁字母中的大写字符和数字组成，不包括'0'和'O'，分成 4 个字符的块，例如 "TWNK-KD5Y-MT3T-E1GS-DRDB-KVTW"。字符由密码学安全的伪随机数生成器（CSPRNG）随机选择。

该字符串可以用作秘密的备份“代码”，实际上与 XEP-0373 中指定的备份代码以及 OpenKeychain 的备份格式 v2中使用的代码相同。

参见
xep-0373/#backup-encryption XEP-0373 §5.4 加密密钥备份
返回
一个人类可读的安全随机字符串。
