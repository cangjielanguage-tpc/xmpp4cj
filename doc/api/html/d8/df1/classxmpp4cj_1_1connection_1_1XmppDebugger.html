详细描述

public abstract class XmppDebugger

允许实现类调试 XML 传输的接口，即显示 XML 传输的 GUI 窗口。

每个该接口的实现 必须 有一个公共构造函数，接受以下参数：XMPPConnection、Writer、Reader。
