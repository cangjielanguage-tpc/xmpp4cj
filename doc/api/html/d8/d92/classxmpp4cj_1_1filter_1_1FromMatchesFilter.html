详细描述

用于过滤 “from” 字段与指定 JID 完全匹配的数据包的过滤器。 如果指定的地址是裸 JID，则过滤器将匹配任何裸 JID 与指定 JID 匹配的地址。 如果指定的地址是完整 JID，则过滤器仅在数据包的发件人与指定资源匹配时才匹配。
