func initialize (): Collection<Exception>
 

详细描述

  • 前提:
    1. cangjie不能打包资源文件
      • 可以使用与so/dll分离的资源文件 但不好向下游分发
    2. 本库被限制不能使用反射
    3. Initializer原理:
      • 大部分Initializer主要为了初始化Config和Provider
      • Config目的是触发加载类静态资源 这通过import相应的类 可以自动达成
      • Provider目的是将自定义Provider注册到ProviderManager
  • 结果:
    • 基于配置文件初始化的方式不可能实现
    • 失去反射意味着不可能自动执行Initializer
  • 解决:
    1. 子Initializer各自将自己注册到某个集中的地方 随后集中initialize()
      • 暂不提供
    2. 子Initializer各自通过static init()执行initialize()
  • 示例: ``` class MyInitializer <: XmppInitializer{ static init(){ MyInitializer().initialize() } public override func initialize(): Collection<Exception>{ /* 直接使用ProviderManager添加自定义Provider
