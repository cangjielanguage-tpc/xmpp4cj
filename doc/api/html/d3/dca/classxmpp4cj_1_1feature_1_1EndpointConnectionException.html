详细描述

如果Xmpp无法连接到给定Xmpp服务的所有主机，则会引发此异常。 可以使用EndpointConnectionException#getConnectionExceptions（）检索连接异常，该异常将导致连接失败，并可使用{RemoteConnectionException::getException（）}进行检索。
