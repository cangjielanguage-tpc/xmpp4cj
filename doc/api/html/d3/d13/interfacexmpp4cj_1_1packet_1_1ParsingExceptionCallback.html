Public 成员函数

func handleUnparsableStanza (stanzaData: UnparseableStanza): Unit
 

详细描述

用于接收解析异常的接口。 如果将此类用作回调，则Xmpp将默默地忽略导致解析异常的节，并且 将解析器放在错误节之后。 Xmpp提供了两个预定义的解析异常回调：ExceptionLoggingCallback和ThrowingCallback。
