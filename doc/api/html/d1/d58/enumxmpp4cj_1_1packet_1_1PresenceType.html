详细描述

一个枚举来表示存在类型。请注意，存在类型经常与存在模式混淆。一般来说，如果用户登录到服务器，他们的存在类型是可用，即使模式是离开、请勿打扰等。只有当用户退出服务器时，存在类型才是不可用。
