详细描述

public abstract class XMPPException <: ExceptionExt

执行XMPP操作时发生错误时引发的通用异常。 XMPP服务器可以用错误代码和问题的文本描述来响应错误情况，这些代码和描述封装在XMPPError类中。 在适当的时候，XMPPError实例是此异常的附加实例

当发生流错误时，服务器将在关闭连接之前向客户端发送流错误。 流错误是不可恢复的错误。 当向客户端发送流错误时，将抛出包含服务器发送的StreamError的XMPPException。
