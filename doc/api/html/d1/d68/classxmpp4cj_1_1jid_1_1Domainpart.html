详细描述

XMPP 地址（JID）的“域部分”。

你可以使用 from(String) 从字符串创建这个类的实例。

参见
RFC 6122 § 2.2. 域部分

◆ fromOrNull()

public static func fromOrNull ( cs:  String) : ?Domainpart

从给定的字符序列获取一个域部分（Domainpart），如果输入不是有效的域部分，则返回 None。

参数
cs输入的字符序列。
返回
一个域部分或 None。

◆ fromOrThrowUnchecked()

public static func fromOrThrowUnchecked ( cs:  String) : Domainpart

类似于 from(String)，但如果输入不是有效的域部分，会抛出未检查的 IllegalArgumentException 而不是 XmppStringprepException。

参数
cs应该转换为域部分（Domainpart）的字符序列。
返回
如果没有异常发生，则返回域部分。
异常
IllegalArgumentException如果给定的输入不是有效的域部分。
