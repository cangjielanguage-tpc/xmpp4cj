详细描述

提供一个机制，用于监听通过指定过滤器的消息包（stanza）。 这允许事件风格的编程——每当发现一个新的消息包时， processStanza(Stanza) 方法将被调用。这与 StanzaCollector 提供的功能相反，后者允许你在等待结果时阻塞。

此外，你还可以拦截即将发送的消息包，并对其进行修改。 你可以通过 xmpp4cj.filter.StanzaFilter) 方法注册一个消息包监听器作为拦截器。

参见
XMPPConnection::addAsyncStanzaListener(StanzaListener, xmpp4cj.filter.StanzaFilter)

func processStanza ( packet:  Stanza) : Unit

处理发送到此消息包监听器的下一个消息包。

如果此监听器是同步的，则由单个线程负责调用所有监听器，因此 实现此方法的代码不应阻塞太长时间。

参数
packet要处理的消息包
异常
NotConnectedException如果 XMPP 连接未连接
InterruptedException如果调用线程被中断
NotLoggedInException如果 XMPP 连接未通过身份验证

在 SimpleStanzaListener 内被实现.
