详细描述

public abstract class XmppFuture<V, E> <: CallbackRecipient<V, E> where E <: Exception

XmppFuture 是一个抽象类，实现了 CallbackRecipient 接口。

该类用于处理异步操作的结果，包括成功结果和异常处理。

参数
<V>future 返回值的类型
<E>异常的类型，必须是 Exception 的子类
