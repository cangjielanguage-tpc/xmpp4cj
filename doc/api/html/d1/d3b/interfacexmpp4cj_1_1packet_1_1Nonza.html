详细描述

一个 Nonza，即如 RFC 6120 8 所定义的不是节的所有内容。节是 Message、Presence 和 IQ。其他所有内容都应该继承这个类而不是 Stanza。

清楚地区分节和非节非常重要。例如，普通的流元素不计入 XEP-198 流管理的节计数中。

参见
XEP-0360: Nonzas (are not Stanzas)
