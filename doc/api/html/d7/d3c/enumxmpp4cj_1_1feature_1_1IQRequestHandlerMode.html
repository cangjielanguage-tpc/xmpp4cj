◆ async

async

以异步方式处理 IQ 请求，即并发处理。这并不保证请求按照到达顺序被处理。

◆ sync

sync

以同步方式处理请求，即按到达顺序处理。使用单线程，这意味着其他请求必须等待 直到所有先前的同步请求被处理完毕。出于性能考虑，如果可能的话，请使用 async。
