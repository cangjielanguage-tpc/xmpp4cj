详细描述

public abstract class DNSResolver

该接口的实现定义了一个能够解析 DNS 地址的类。

此抽象类提供了查找服务记录和主机地址的基本功能，并提供对 DNSSEC 的支持。

在给定主机名称上查找 IP 地址。

如果发生错误，将返回 null，并且错误原因将以 HostAddress 的形式添加到 failedAddresses。 如果 DNS 名称存在但没有与之关联的 A 或 AAAA 资源记录，则返回空列表。 否则，如果解析成功并且至少有一个 A 或 AAAA 资源记录，则返回非空列表。

参数
name要查找的 DNS 名称
lookupFailures在查找期间发生的异常列表
dnssecMode选择的 DNSSEC 模式
返回
包含 IP 地址的列表
