详细描述

表示扩展元素的接口。

扩展元素是一个带有根元素名称和命名空间的 XML 子文档。扩展元素用于提供超出基本 XMPP 规范的扩展功能。扩展元素的例子包括消息事件、消息属性和额外的存在数据。IQ 节对扩展元素的支持有限。

这个类主要用于 XMPP 节中的扩展内容，充当所谓的“扩展元素”。更多信息请参见 RFC 6120 § 8.4 扩展内容。
