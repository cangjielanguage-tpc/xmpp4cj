详细描述

Like ArrayBlockingQueue but with additional shutdown() and start methods. Will throw IllegalStateException if Queue has been shutdown on take() and poll(Duration).

参数
<E>the type of elements held in this collection

◆ put()

public func put ( e:  E) : Unit

Inserts the specified element into this queue, waiting if necessary for space to become available.

This may throw an IllegalStateException in two cases

  1. If the queue was shut down.
  2. If the thread was was interrupted.

So you have to check which is the case, e.g. by calling isShutdown().

参数
ethe element to add.
异常
IllegalStateExceptionif interrupted while waiting or if the queue was shut down.
