详细描述

确定请求的 DNSSEC 安全模式。 注意：Xmpp 对 DNSSEC/DANE 的支持仍然处于实验阶段！

默认选项 'disabled' 表示不进行任何 DNSSEC 或 DANE 验证。如果使用 'needsDnssec'， 则如果用于连接 XMPP 服务的资源记录未通过 DNSSEC 认证，则无法建立连接。此外，如果使用 'needsDnssecAndDane'，则会使用 DANE 验证 XMPP 服务的 TLS 证书。
