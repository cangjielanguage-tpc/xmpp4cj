计算最后已知的已处理节的数量和新报告的已处理节的数量之间的差值，同时考虑到新值可能在 2 的 32 次方减 1 之后回绕。

◆ incrementHeight()

public static func incrementHeight ( height:  Int64) : Int64

增加 Stream Management height 计数器.

引用 XEP-198 4.: “在不太可能的情况下，如果在流管理会话期间处理的节（stanza）数量超过 XML 模式第 2 部分[10]中指定的无符号整数数据类型所能表示的数字（即 2 的 32 次方），那么‘h’的值应从 2 的 32 次方减 1 重置回零，而不是递增到 2 的 32 次方。”

参数
height
返回
增加后的 height
