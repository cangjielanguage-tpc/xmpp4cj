详细描述

管理用于解析 XMPP 数据包的自定义 XML 子文档的提供程序。存在两种类型的提供程序：

  • IQProvider – 将 IQ 请求解析为对象。
  • PacketExtension – 将附加到数据包的 XML 子文档解析为 PacketExtension 实例。

IQProvider

默认情况下，Xmpp 仅知道如何处理具有子包的 IQ 数据包，这些子包位于少数几个命名空间中，例如：

  • jabber:iq:auth
  • jabber:iq:roster
  • jabber:iq:register

由于 XMPP 及其扩展中有更多的 IQ 类型，因此提供了一个可插拔的 IQ 解析机制。IQ 提供程序可以通过编程方式注册，也可以通过创建提供程序文件进行注册。该文件是一个 XML 文档，其中包含一个或多个 iqProvider 条目，如下例所示：

 <?xml version="1.0"?>
 <xmppProviders>
     <iqProvider>
         <elementName>query</elementName>
         <namespace>jabber:iq:time</namespace>
         <className>Time</className>
     </iqProvider>
 </xmppProviders>

每个 IQ 提供程序都与一个元素名称和一个命名空间相关联。如果多个提供程序条目试图注册以处理相同的命名空间，则从类路径加载的第一个条目将具有优先权。IQ 提供程序类可以实现 IQProvider 接口，也可以扩展 IQ 类。在前一种情况下，每个 IQProvider 负责解析原始 XML 流以创建一个 IQ 实例。在后一种情况下，使用 bean 内省来尝试使用在 IQ 节 XML 中找到的值自动设置 IQ 实例的属性。例如，一个 XMPP 时间节类似于以下内容： 

 <iq type='result' to='joe@e.nosp@m.xamp.nosp@m.le.co.nosp@m.m' from='mary@.nosp@m.exam.nosp@m.ple.c.nosp@m.om' id='time_1'>
     <query xmlns='jabber:iq:time'>
         <utc>20020910T17:58:35</utc>
         <tz>MDT</tz>
         <display>Tue Sep 10 12:58:35 2002</display>
     </query>
 </iq>

为了使这个节自动映射到上面提供程序文件中列出的 Time 对象，它必须具有 setUtc(String)、setTz(String) 和 setDisplay(String) 方法。内省服务将自动尝试根据 IQ 实例期望的类型将 XML 中的字符串值转换为布尔值、整数、长整数、浮点数、双精度数或类。

还存在一个用于节扩展的可插拔系统，即消息和存在数据包的自定义命名空间中的子元素。每个扩展提供程序都在 xmpp.providers 文件中使用名称空间进行注册，如下例所示：

 <?xml version="1.0"?>
 <xmppProviders>
     <extensionProvider>
         <elementName>x</elementName>
         <namespace>jabber:iq:event</namespace>
         <className>MessageEvent</className>
     </extensionProvider>
 </xmppProviders>

如果多个提供程序条目试图注册以处理相同的元素名称和命名空间，则从类路径加载的第一个条目将具有优先权。每当在数据包中找到节扩展时，解析将传递给正确的提供程序。每个提供程序都可以实现 PacketExtensionProvider 接口。在前一种情况下，每个扩展提供程序负责解析原始 XML 流以构造一个对象。在后一种情况下，使用 bean 内省来尝试使用在节扩展子元素中的值自动设置类的属性。当没有为元素名称和命名空间组合注册扩展提供程序时，将把子包的所有顶级元素存储在 DefaultPacketExtension 对象中，然后将其附加到数据包上。

public static func getExtensionProvider ( elementName:  String,
namespace:  String 
) : ?ExtensionElementProvider<ExtensionElement>

返回注册到指定 XML 元素名称和命名空间的节扩展提供程序。例如，如果一个提供程序注册到元素名称为“x”且命名空间为“jabber:x:event”，那么以下节将触发该提供程序：

 <message to='romeo.nosp@m.@mon.nosp@m.tague.nosp@m..net' id='message_1'>
     <body>Art thou not Romeo, and a Montague?</body>
     <x xmlns='jabber:x:event'>
         <composing/>
     </x>
 </message>

注意：此方法通常仅由内部 Xmpp 类调用。

参数
elementName与扩展提供程序相关联的元素名称。
namespace与扩展提供程序相关联的命名空间。
返回
扩展提供程序。
