◆ disabled

disabled

通过TLS加密的安全性被禁用，只会使用未加密的连接。如果服务器只提供TLS加密，则连接将失败。

◆ ifpossible

ifpossible

只要可用，就会使用TLS加密的安全性。这是默认设置。

除非不能使用{}，否则不要使用此设置。攻击者可以轻松地执行中间人攻击并阻止TLS的使用，从而为您留下未加密（且未经验证）的连接。

◆ required

required

需要通过TLS加密进行安全保护才能连接。如果服务器不提供TLS或TLS协商失败，则与服务器的连接将失败。
