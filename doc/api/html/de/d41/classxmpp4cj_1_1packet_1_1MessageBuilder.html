详细描述

MessageBuilder 类用于构建 XMPP 消息（Message）对象的方便构建器。

该类为 Message 对象提供了灵活的构建选项，包括设置消息类型、主体和主题等属性。 它支持从现有的 Message 实例中复制设置，并提供了一系列方法用于设置消息的不同部分。
