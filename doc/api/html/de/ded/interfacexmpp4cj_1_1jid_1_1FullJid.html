详细描述

这是一个关于 XMPP 地址（JID）的接口定义，代表一个具有资源部分（Resourcepart）的 JID，可以是EntityFullJid或DomainFullJid类型。

Examples:

  • local.nosp@m.part.nosp@m.@doma.nosp@m.in.p.nosp@m.art/resourcepart
  • domain.part/resourcepart
