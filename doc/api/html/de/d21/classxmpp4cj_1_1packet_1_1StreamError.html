详细描述

表示流错误数据包。流错误是不可恢复的错误，在将流错误发送给客户端后，服务器将关闭底层的 TCP 连接。 以下是 XMPP 规范中定义的流错误列表：

流错误
代码描述
bad-format实体发送了无法处理的 XML
unsupported-encoding实体发送了不支持的命名空间前缀
bad-namespace-prefix远程服务器超时
conflict服务器正在关闭此实体的活动流，因为已启动的新流与现有流冲突
connection-timeout实体在一段时间内未在流上生成任何流量
host-gone流头中发起实体提供的“to”属性的值对应于不再由服务器托管的主机名
host-unknown流头中发起实体提供的“to”属性的值与服务器托管的主机名不对应
improper-addressing在两个服务器之间发送的节缺少“to”或“from”属性
internal-server-error服务器遇到了配置错误
invalid-from“from”地址中提供的 JID 或主机名与授权的 JID 不匹配
invalid-namespace流的命名空间名称无效
invalid-xml实体在流上发送了无效的 XML
not-authorized实体在流进行身份验证之前尝试发送数据
policy-violation实体违反了一些本地服务策略
remote-connection-failed服务器无法正确连接到远程实体
resource-constraint服务器缺乏为流提供服务所需的系统资源
restricted-xml实体尝试发送受限制的 XML 特性
see-other-host服务器不会为发起实体提供服务，而是将流量重定向到另一个主机
system-shutdown服务器正在关闭，所有活动流都在被关闭
undefined-condition错误条件不是此列表中其他条件所定义的那些之一
unsupported-encoding发起实体已使用不支持的编码对流进行编码
unsupported-stanza-type发起实体已发送流的不支持的一级子元素
unsupported-version流头中发起实体提供的“version”属性的值指定了不支持的 XMPP 版本
not-well-formed发起实体发送了格式不正确的 XML

流错误语法： 

 

 <stream:error>

   <defined-condition xmlns='urn:ietf:params:xml:ns:xmpp-streams'/>

   [<text xmlns='urn:ietf:params:xml:ns:xmpp-streams'

      xml:lang='langcode'>

   可选的描述性文本

   </text>]

   [可选的特定于应用程序的条件元素]

 </stream:error>
