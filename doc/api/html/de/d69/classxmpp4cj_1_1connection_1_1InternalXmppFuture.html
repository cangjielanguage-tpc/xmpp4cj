详细描述

InternalXmppFuture 是一个内部类，扩展了 XmppFuture，用于处理异步操作的结果。

该类提供了设置结果或异常的功能，并在这些状态变化时通知所有等待的线程。

参数
<V>结果的类型
<E>异常的类型，必须是 Exception 的子类
