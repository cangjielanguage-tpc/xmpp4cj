详细描述

public abstract class IQ <: Stanza & IqView

基础 IQ（信息/查询）包。IQ 包用于在服务器上获取和设置信息，包括认证、通讯录操作和创建账户。每个 IQ 节都有一个特定的类型，指示正在采取的操作类型：“get”、“set”、“result”或“error”。

IQ 包可以包含一个存在于特定 XML 命名空间中的子元素。元素名称和命名空间的组合决定了它是哪种类型的 IQ 节。一些 IQ 子包片段的示例：

  • <query xmlns="jabber:iq:auth"> – 一个认证 IQ。
  • <query xmlns="jabber:iq:private"> – 一个私有存储 IQ。
  • <pubsub xmlns="${JABBER_PROTOCAL_NAMESPACE_PREFIX}/pubsub"> – 一个发布订阅 IQ。

◆ getIQChildElementBuilder()

protected func getIQChildElementBuilder ( xml:  IQChildElementXmlStringBuilder) : ?IQChildElementXmlStringBuilder
protected

这个方法必须由 IQ 子类重写以创建它们的子内容。重要的是你不要使用构建器添加最终的结束标签。这将在最终存在的 ExtensionElement 被添加后由 IQChildElementXmlStringBuilder 自动完成。

例如，要创建一个带有额外属性和一个附加子元素的 IQ： 

 

 <iq to='foo@example.org' id='123'>

   <bar xmlns='example:bar' extraAttribute='blaz'>

      <extraElement>elementText</extraElement>

   </bar>

 </iq>

getIQChildElementBuilder 的主体如下所示： 

 

 

 

 xml.attribute("extraAttribute", "blaz")

 xml.rightAngleBracket()

 xml.element("extraElement", "elementText")

如果你的 IQ 只包含属性而没有子元素，即它可以表示为空元素，那么你可以将其标记为这样。 

 xml.attribute("myAttribute", "myAttributeValue")
 xml.setEmptyElement()

如果你的 IQ 不包含任何属性或子元素（除了 ExtensionElement 之外），考虑继承 SimpleIQ 代替。

参数
xml一个预先创建的构建器，已经设置了子元素和“xmlns”属性。
返回
创建 IQ 子内容的构建器。
