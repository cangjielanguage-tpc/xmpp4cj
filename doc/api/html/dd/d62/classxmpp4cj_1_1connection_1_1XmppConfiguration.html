详细描述

表示Xmpp的配置。该配置用于：

  • 通过在启动时加载类来初始化类。
  • 获取当前Xmpp版本。
  • 获取和设置全局库行为，如时间段等待服务器对数据包的回复。注意：设置这些值通过API将覆盖配置文件中的设置。

*配置设置存储在xmpp_config_xml中。

◆ static var TRUELY_ASYNC_SENDS

var TRUELY_ASYNC_SENDS = false

如果启用，将导致AbstractXMPPConnection为每个异步发送操作创建一个线程。 这是为了解决Xmpp的一个缺点，即某些发送操作即使应该异步，也不是异步的。 这是一个专家设置，如果您不了解后果或被告知要这样做，请不要切换。请注意，预计在未来的Xmpp版本中不会需要这样做。
