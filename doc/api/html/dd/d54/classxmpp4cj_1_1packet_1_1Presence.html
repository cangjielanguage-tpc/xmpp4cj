详细描述

表示 XMPP 存在节。每个存在节都有一个类型，以下是类型的值：

  • 可用 –（默认）表示用户可接收消息。
  • 不可用 – 用户不可接收消息。
  • 订阅 – 请求订阅接收者的存在。
  • 已订阅 – 同意发送者的存在订阅。
  • 取消订阅 – 请求移除对发送者存在的订阅。
  • 已取消订阅 – 同意移除对发送者存在的订阅。
  • 错误 – 存在节包含错误消息。

一些属性是可选的：

  • 状态 – 描述用户存在的自由格式文本（例如，去吃午饭了）。
  • 优先级 – 发送者资源的非负数字优先级。最高资源优先级是未指定特定资源的数据包的默认接收者。
  • 存在模式 – 五种存在模式之一：可用（默认）、聊天、离开、长时间离开和请勿打扰。

存在节有两个用途。首先，通知服务器用户当前的存在状态。其次，它们用于在通讯录中订阅和取消订阅用户。

◆ isAvailable()

public func isAvailable ( ) : Bool

如果存在类型是可用（在线），则返回 true，如果用户不可用（离线），或者这是一个参与订阅操作的存在包，则返回 false。这是一个方便方法，等同于getType() == PresenceType.available。请注意，即使用户可用，他们的存在模式也可能是离开、长时间离开或请勿打扰。使用isAway()确定用户是否离开。

返回
如果存在类型是可用，则为 true。

◆ isAway()

public func isAway ( ) : Bool

如果存在类型为type#available并且存在 模式为mode#away、extended away，或 {}。当输入类型或模式时，将返回False 是任何其他值，包括当前状态类型不可用（脱机）时。 这是一种方便的方法，相当于 类型==类型可用&amp；（mode==mode.away|| mode==mode.xa|| mode==mode.dnd）。

返回
如果存在类型可用，并且存在模式为away、xa或dnd，则返回true。
