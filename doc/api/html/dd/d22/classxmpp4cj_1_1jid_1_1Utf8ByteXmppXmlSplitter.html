详细描述

XmppXmlSplitter的扩展版本，允许输入为字节或表示 UTF-8 编码的 XMPP XML 字符串的ByteBuffer，就像它们来自网络套接字一样。

这个类遵循 RFC 6120 11.6 的字节顺序标记（BOM）要求，并将 BOM 视为零宽度不间断空格，而不是字节顺序标记。
