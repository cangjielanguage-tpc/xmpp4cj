详细描述

MultiMap的轻量级实现，即能够为每个键保存多个值的Map。 此MultiMap使用LinkedHashMap和ArrayList来保持其条目的顺序。

参数
<K>映射使用的键的类型。
<V>映射使用的值的类型。
