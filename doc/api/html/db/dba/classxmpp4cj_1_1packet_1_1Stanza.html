详细描述

public abstract class Stanza <: StanzaView & TopLevelStreamElement & ToString

XMPP 节的基类。

每个节都有一个唯一的 ID（自动生成，但可以被覆盖）。IQ 节需要节 ID，对于存在和消息节则建议使用。可选地，可以设置“to”和“from”字段。

XMPP 节有 Message、IQ 和 Presence。因此它们都是这个类的子类。如果你认为你需要子类化这个类，那么你可能做错了什么。

使用 StanzaBuilder 来构建节实例。这个类的所有实例修改方法都已过时，尽管目前并非所有方法都被标记为过时，但绝不能使用。

参见
RFC 6120 § 8. XML Stanzas
