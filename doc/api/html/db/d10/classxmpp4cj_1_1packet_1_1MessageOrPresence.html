详细描述

public abstract class MessageOrPresence <: Stanza

MessageOrPresence 是一个抽象类，表示可以作为消息或存在状态的 XMPP 信令。

此类扩展自 Stanza，并为消息（Message）和存在状态（Presence）提供了公共基础。 通常被具体的消息或存在状态实现类继承。
