◆ newXmlParser()

public static func newXmlParser ( reader:  InputStream) : XmlPullParser

创建一个适用于解析 XMPP 的新 XmlPullParser。 这尤其意味着启用了 FEATURE_PROCESS_NAMESPACES。

请注意，并非所有的 XmlPullParser 实现都会在解析器处于 START_ELEMENT 或 END_ELEMENT 时在 getText() 方法上返回一个字符串。 因此，在使用解析器时，你不能依赖这种行为。

参数
reader用于读取 XML 数据的读取器。
返回
一个适用于 XMPP 解析的 XmlPullParser。
异常
XmlPullParserException如果发生 XmlPullParserException。
