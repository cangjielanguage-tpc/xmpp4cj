用于检查给定的字符序列是否是一个典型且有效的实体裸 JID。 该方法执行与isValidEntityBareJid(CharSequence)相同的检查，并且还额外验证 JID 的域部分是否至少包含一个点（'.'）字符。

“…TypicalValidEntityBareJid (CharSequence)” 方法在你期望用户始终输入完全限定域名（FQDN）作为域部分时很有用。 而 “isValidEntityBareJid (CharSequence)” 和 “validateEntityBareJid” 方法也接受像 “foo 这样的输入， 但 “是典型 JID” 方法要求域部分包含一个点，例如 “foo@.nosp@m.exam.nosp@m.ple.o.nosp@m.rg”。

参数
jidcs要检查的 JID 字符序列。
返回
如果输入是有效的典型实体裸 JID，则返回一个EntityBareJid实例，表示给定的 JID 字符序列。
异常
NotAEntityBareJidStringException如果给定的字符序列不是裸 JID
