详细描述

ToMatchesFilter 是一个用于过滤与 "to" 字段匹配的地址的过滤器。 该类扩展了 AbstractFromToMatchesFilter，允许根据给定的 JID 进行过滤。

◆ create()

public static func create ( address:  ?Jid) : ToMatchesFilter

创建一个匹配 "to" 字段的过滤器。如果过滤地址是裸 JID，则比较 过滤地址与裸 "from" 地址；否则，比较过滤地址与全 "from" 地址。

参数
address要过滤的地址。如果给定 null，则 Stanza 不能有 "from" 地址。
