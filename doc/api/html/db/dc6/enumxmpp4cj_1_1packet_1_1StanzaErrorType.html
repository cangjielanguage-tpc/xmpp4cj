详细描述

一个表示错误类型的类。类型有：

  • XMPPErrorType.WAIT - 等待后重试（错误是暂时的）
  • XMPPErrorType.CANCEL - 不要重试（错误不可恢复）
  • XMPPErrorType.MODIFY - 在更改发送的数据后重试
  • XMPPErrorType.AUTH - 在提供凭证后重试
  • XMPPErrorType.CONTINUE - 继续（条件只是一个警告）
