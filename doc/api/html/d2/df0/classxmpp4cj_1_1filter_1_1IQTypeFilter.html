详细描述

IQ 数据包类型的过滤器。仅当数据包是 IQ 包并且与构造函数中提供的类型匹配时返回 true。

检查指定的 IQ 数据包是否匹配当前的 IQ 类型。

参数
iq要检查的 IQ 数据包对象。
返回
如果 IQ 数据包的类型与当前过滤器的类型相同，则返回 true；否则返回 false。
