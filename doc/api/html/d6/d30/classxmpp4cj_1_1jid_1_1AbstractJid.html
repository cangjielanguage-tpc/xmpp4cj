◆ isParentOf()

public override func isParentOf ( jid:  Jid) : Bool

用于检查当前的 JID 是否是另一个给定 JID 的 “父级”。“父级” 关系的定义如下：在 JID 的各个部分（本地部分、域部分和资源部分）相等的前提下，如果满足特定条件，则认为当前 JID 是另一个 JID 的父级。通过一个表格展示不同情况下的判断结果： 

 | this JID (parentOf) | other JID           | result |
 |---------------------+---------------------+--------|
 | dom.example         | dom.example         | true   |
 | dom.example         | dom.example/res     | true   |
 | dom.example         | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | true   |
 | dom.example         | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | true   |
 | dom.example/res     | dom.exmple          | false  |
 | dom.example/res     | dom.example/res     | true   |
 | dom.example/res     | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | false  |
 | dom.example/res     | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | false  |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | dom.example         | false  |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | dom.example/res     | false  |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | true   |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | true   |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | dom.example         | false  |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | dom.example/res     | false  |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e     | false  |
 | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | loc@d.nosp@m.om.e.nosp@m.xampl.nosp@m.e/res | true   |
