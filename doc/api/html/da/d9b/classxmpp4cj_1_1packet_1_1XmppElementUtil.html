详细描述

XmppElementUtil 类提供了一些用于处理 XMPP 元素的实用方法。 这个类主要用于获取 XMPP 元素的 QName，以及从存储的元素中提取特定类型的扩展元素。

public static func getQNameFor ( qnameFrom:  ClassId) : QName

根据给定的 FullyQualifiedElement 类返回对应的 QName。 如果 QName 已经被缓存，则直接返回缓存中的值。 如果未缓存，则尝试从类的静态字段 QNAME 获取。 如果 QNAME 不存在，则使用 ELEMENT 和 NAMESPACE 字段构造 QName。
