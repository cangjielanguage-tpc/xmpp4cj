详细描述

public abstract class AbstractIqRequestHandler <: IQRequestHandler

抽象类，用于创建 IQ 请求处理器的便利类。

该类用于处理 XMPP 中的 IQ 请求。只允许处理类型为“get”和“set”的请求。
