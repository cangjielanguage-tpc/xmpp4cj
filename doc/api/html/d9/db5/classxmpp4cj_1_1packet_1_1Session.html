详细描述

将会发送到服务器以建立会话的 IQ 节。

如果服务器支持会话，它必须在流认证完成后向客户端通告的流特性中包含一个session元素。当客户端被告知服务器要求建立会话时，如果它希望使用即时消息和存在功能，则必须建立会话。
