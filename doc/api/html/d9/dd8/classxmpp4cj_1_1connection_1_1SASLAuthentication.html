详细描述

该类负责使用 SASL 验证用户，绑定资源到连接并与服务器建立会话。

一旦 TLS 已成功协商（即连接已加密），便可以向服务器注册或使用 SASL 进行身份验证。 如果服务器支持 SASL，则 Xmpp 将尝试使用 SASL 进行身份验证。

服务器可能支持多种用于身份验证的 SASL 机制。默认情况下，Xmpp 提供几种 SASL 机制，但可以注册新的 SASL 机制。 使用 registerSASLMechanism(SASLMechanism) 注册新机制。
