详细描述

XMPP 地址，也称为 JID（以前是 “Jabber Identifier” 的缩写），它在 XMPP 网络中作为全局唯一的地址。

JIDs 可以通过xmpp4cj.jid.JidCreate工具类从String创建。 

 let jid:Jid = JidCreate.froms("juliet@capulet.org/balcony")
 let bareJid:EntityBareJid = JidCreate.entityBareFrom("romeo@montague.net")

这是所有 JID 类型的超接口，JID 由两个维度构建：裸（Bare）/ 全（Full）和 域（Domain）/ 实体（Entity）。

  1. 每个 JID 至少由一个域部分（xmpp4cj.jid.Domainpart）组成。
  2. 裸 JID 类型没有资源部分（xmpp4cj.jid.Resourcepart），全 JID 类型总是有资源部分。
  3. 域 JID 类型没有本地部分（xmpp4cj.jid.Localpart），而实体 JID 类型总是有本地部分。

一些 JID 类型的示例：

XMPP Address Types
Example Type
example.org xmpp4cj.jid.DomainBareJid
example.org/resource xmpp4cj.jid.DomainFullJid
user@.nosp@m.exam.nosp@m.ple.o.nosp@m.rg xmpp4cj.jid.EntityBareJid
user@.nosp@m.exam.nosp@m.ple.o.nosp@m.rg/resource xmpp4cj.jid.EntityFullJid

可以使用 toString() 方法获取表示 JID 的转义字符串，或者使用 asUnescapedString() 方法获取 JID 的未转义字符串。

URL Encoded JIDs

如果 JID 应该作为路径名的一部分存储，例如作为文件名，那么 JID 的 URL 编码表示是理想的。 可以使用 asUrlEncodedString() 方法获取此信息。 JidCreate API 提供了从 URL 编码的字符串创建 JIDs 的方法，如 xmpp4cj.jid.JidCreate#fromUrlEncoded(String) 。

参见
RFC 6120 (XMPP: Core) § 2.1 Global Addresses
RFC 6122 (XMPP: Address Format) § 2.1 Fundamentals

◆ asUnescapedString()

func asUnescapedString ( ) : String

此方法用于返回这个 JID 的未转义字符串表示形式。

由于某些 Unicode 码点在 JID 的本地部分（localpart）中是不被允许的，按照所需的 stringprep 规范，这些码点在实际的 JID 中需要被转义。未转义的 JID 表示形式仅用于向人类用户展示或用于与非 XMPP 系统进行交互。

例如，如果用户输入 'at&t guy@example.com'，使用xmpp4cj.jid.JidCreate创建的转义后的实际 JID 将是'at\26t\20guy@example.com'，这是 Jid#toString() 方法将返回的结果。而 Jid#asUnescapedString() 方法将再次返回'at&t guy@example.com'。

返回
这个 JID 的未转义字符串表示。

在 DomainAndResourcepartJid, DomainpartJid, LocalAndDomainpartJid , 以及 LocalDomainAndResourcepartJid 内被实现.

◆ isParentOf() [5/5]

func isParentOf ( jid:  Jid) : Bool
